# Nepunan Calculator - DCIT 26 Laboratory 1

A responsive calculator website built with React and Tailwind CSS.

## Requirements implemented

- React components
- Tailwind CSS
- React state and event handling
- Number and operator buttons
- Dynamic calculations
- Clear/reset functionality
- Backspace
- Keyboard support
- Division-by-zero error handling
- Responsive layout
- Instructions/User Guide

## Run locally

Install Node.js first, then open this folder in a terminal:

```bash
npm install
npm run dev
```

Open the local address shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## Deploy

The easiest option is Vercel:

1. Upload this project to GitHub.
2. Go to Vercel and import the GitHub repository.
3. Vercel will detect the Vite/React project.
4. Deploy.
5. Copy the public `.vercel.app` URL for submission.

Project folder name: `Nepunan_Calculator_Laboratory1`
